INSTAGRAM 連携設定

このサイトから直接投稿するには、Instagram Graph API（公式API）と、画像を公開URLにするための Cloudinary（無料枠あり）が必要です。設定値はこのPCのブラウザ内にだけ保存されます。未設定でも「全画像を保存＋本文コピー」で手動投稿できます。

Instagram Graph API
Cloudinary（画像の公開URL）

アップロードされた画像はInstagramが取得できるよう公開URLになります。投稿後はCloudinaryの管理画面から削除できます。

準備手順ガイド（初回のみ）
  1. Instagramアプリでアカウントをプロアカウント（ビジネス／クリエイター）に切り替える。
  2. Facebookページを作成し、Instagramアカウントとリンクする（Facebookログイン経由の場合）。
  3. Meta for Developersでアプリを作成し、「Instagram Graph API」を追加する。
  4. Graph APIエクスプローラで instagram_basic instagram_content_publish pages_show_list pages_read_engagement の権限付きトークンを発行し、長期トークン（約60日有効）に交換する。
  5. /me/accounts でページIDを確認し、/{ページID}?fields=instagram_business_account でInstagramユーザーIDを取得する。
  6. Cloudinaryに無料登録 → Settings → Upload → Upload presets で Unsigned のプリセットを作成し、Cloud nameとプリセット名を入力する。
  7. 「接続テスト」でアカウント名が表示されれば準備完了です。

※ フィード投稿は縦横比 4:5〜1.91:1 のJPEGのみ、カルーセルは最大10枚です（API仕様）。9:16はストーリーズとして投稿できます。
