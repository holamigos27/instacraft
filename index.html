画像の公開先

Instagramは画像を公開URLから取り込みます。投稿する画像をどこに置くかを選びます。

Cloudinary に無料登録 → Settings → Upload → Upload presets で Unsigned のプリセットを作り、Cloud name とプリセット名を入力します。

Makeの準備手順（初回のみ・チームで1回）
  1. Instagramアカウントをビジネスアカウントにし、Facebookページとリンクする（Makeの仕様で、クリエイターアカウントは不可）。
  2. make.com に無料登録し、「Create a new scenario」を開く。
  3. 最初のモジュールに Webhooks › Custom webhook を置き、「Add」でWebhookを作成 → 表示された URLをコピーして左の欄に貼り付け、保存。
  4. 「Makeに試し送信」を押す（Make側で「Successfully determined」と出れば、送られるデータの形が登録されます）。
  5. Webhookの後ろに Router を置き、2本に分ける：
    • 1本目（フィルター：mode = publish かつ count = 1）→ Instagram for Business › Create a photo post。Photo URL に image_url、Caption に caption。
    • 2本目（フィルター：mode = publish かつ count ≥ 2）→ Create a carousel post。Files の「Map」をオンにして images[] を割り当て、Caption に caption。
  6. Instagramモジュールの初回に「Create a connection」→ Facebookでログインし、投稿するページ／アカウントを選ぶ。
  7. （任意）各ルートの最後に Webhooks › Webhook response を置き、Body を {"ok":true,"id":"{{投稿ID}}"} にすると、こちらで完了を確認できます。
  8. シナリオを保存して ON（Immediately）にすれば準備完了です。

※ フィード投稿は縦横比 4:5〜1.91:1 のJPEG、カルーセルは最大10枚です。MakeのInstagram連携にはストーリーズ投稿がないため、ストーリーズは「全画像を保存」からアプリで投稿してください。

Graph APIの準備手順
  1. Instagramアプリでアカウントをプロアカウント（ビジネス／クリエイター）に切り替える。
  2. Facebookページを作成し、Instagramアカウントとリンクする（Facebookログイン経由の場合）。
  3. Meta for Developersでアプリを作成し、「Instagram Graph API」を追加する。
  4. Graph APIエクスプローラで instagram_basic instagram_content_publish pages_show_list pages_read_engagement の権限付きトークンを発行し、長期トークン（約60日有効）に交換する。
  5. /me/accounts でページIDを確認し、/{ページID}?fields=instagram_business_account でInstagramユーザーIDを取得する。
  6. 「接続テスト」でアカウント名が表示されれば準備完了です。
